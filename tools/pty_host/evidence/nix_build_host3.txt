Attach to a running host/daemon over its unix socket.

Modes: * `--socket <daemon>` (no `--instance`, no `--debug`) -> HOST-3 multi agent DASHBOARD: agent sidebar + selected agent's live pane. * `--socket <host> --debug` -> PTYH-3 single-host split debug TUI. * otherwise -> PTYH-2 raw passthrough against a single host.

Usage: ham-pty-host attach [OPTIONS] --socket <SOCKET>

Options:
      --socket <SOCKET>
          Unix socket path of the host/daemon to attach to

      --debug
          Render the in-app split-screen debug TUI (single-host, PTYH-3)

      --instance <INSTANCE>
          Attach to a specific daemon agent by instance id (HOST-4). Absent => the multi-agent dashboard (HOST-3)

  -h, --help
          Print help (see a summary with '-h')
