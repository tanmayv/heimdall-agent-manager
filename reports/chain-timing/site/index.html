Metric definitions

Chain elapsed
Cutoff minus chain creation: wall-clock age, not a sum of task durations.
Created / first-start elapsed
Creation or first task start to completion/cancellation; unfinished tasks stop at cutoff. Queue-only tasks show waiting age, not a completed duration.
Pre-start wait
First start minus creation, or cutoff minus creation when unstarted. Dependency, dispatch and hold wait cannot be split from these records.
Attempt envelope
Union of Hub runtime-facet started_at/ended_at intervals clipped at cutoff. A logical attempt can span restarts/renewed leases; this is not exact live-lease or productive time.
Review bounds / unclassified
Earliest-to-latest reviewer comments in the same gap between attempt envelopes. These are observed bounds, not full review lease durations. Remaining first-start elapsed is unclassified, not measured model thinking.
Shell sum / union
Sum of unique Hub session spans; union removes overlap. Includes launch and exit-delivery latency. Separate subprocess runtime, launch queue and CPU use are unknown.
Files / added / deleted LOC
Exact retained net diff between the task-specific Git base and checkpoint/submitted head, with rename detection. Integration bases remove inherited changes. Old C1/C1a retained rows overlap and must not be added.
Gross churn
Deduplicated nonmerge first-parent commit diffs. Merge resolution-only remerge diffs are separate diagnostics because synthetic conflict cleanup is not authored LOC.
